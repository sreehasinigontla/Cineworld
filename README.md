# 🎬 Cineworld – Movie Information Website

Welcome to **Cineworld**, a modern and visually engaging movie information website designed for movie lovers!

Cineworld provides an attractive platform to explore movies, discover movie details, view ratings, learn about cast members, watch trailers, and explore related movies.

## 🌟 Features

- **Popular Movies:** Browse a collection of popular movies with attractive poster cards.
- **Movie Ratings:** View movie ratings displayed on movie posters.
- **Movie Information:** Explore movie details, genres, release information, and story descriptions.
- **Cast & Crew:** Discover actors and their roles.
- **Movie Trailers:** Watch movie trailers through an embedded YouTube video section.
- **Related Movies:** Explore additional movies related to the featured movie.
- **Interactive Design:** Smooth hover effects, transitions, and attractive animations.
- **Responsive Layout:** Flexible layouts designed to work across different screen sizes.

## 🎨 Design Highlights

- Modern dark-themed interface.
- Attractive purple, red, and golden color combinations.
- Stylish movie poster cards.
- Smooth hover animations and visual effects.
- Clean typography and organized sections.
- Cinema-inspired user interface.

## 🛠️ Technologies Used

- **HTML5** – For webpage structure and content.
- **CSS3** – For styling, layouts, animations, and responsive design.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open `index.html` in your web browser.
5. Explore the Cineworld website!

## 🎯 Project Objective

The main objective of Cineworld is to create an attractive and user-friendly movie information website using HTML and CSS. This project helps demonstrate frontend web development skills, creative UI design, webpage structuring, and responsive styling.
